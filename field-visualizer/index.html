        The Theremini does not expose raw capacitance directly over standard MIDI, so this visual uses incoming messages as a disturbance proxy.

        Kinect mode expects the local bridge at http://localhost:8182. Run start-kinect-bridge.ps1 and close any other app that may already be using the sensor.

        Foil experiments can change capacitance dramatically. Start with loose, external pieces near the antenna before wrapping anything, and avoid blocking vents or power sections.
